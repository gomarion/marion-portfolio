## A section heading

Section headings use the same typeface as the "What I do" titles. Lists work as expected:

- Custom themes for Shopify, Ghost, WordPress and Tumblr
- Website operations: hosting, deployments, DNS and performance
- Building with AI-assisted tools like Claude Code

And numbered steps:

1. Write the post as an `.mdx` file in `src/content/blog`.
2. Preview it with `npm run dev`.
3. Remove `draft: true` and push to publish.
